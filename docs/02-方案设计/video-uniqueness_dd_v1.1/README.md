# video-uniqueness DD Addendum 目录

大范围扩展时在此目录创建增量补篇，不修改主 DD。

## 命名规则

```
video-uniqueness_dd_v1.1/video-uniqueness_dd_p{N}_addendum.md
```

- `p1` = 第一个大扩展，`p2` = 第二个，以此类推
- 每篇 Addendum 独立描述一个新增模块/能力

## 触发条件

- 新增功能模块
- 新增系统能力
- 新增架构范围
- 对原 DD 产生较大影响的扩展设计
