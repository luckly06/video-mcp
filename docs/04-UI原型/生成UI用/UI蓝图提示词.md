# 视频去重工位 station · PC Web UI 蓝图提示词

> 阶段：阶段一 · UI 蓝图（待人工确认）
> 
> 本文是后续 PC Web 前端工程实现的唯一视觉与页面结构契约。未获得人工确认前，不得据此改写前端视觉实现。

## 1. 项目定位

产品：视频去重工位 station（Video Uniqueness Station）。

目标用户：短视频矩阵分发运营者。用户不需要阅读 Python、MCP、Hook 或 ffmpeg 实现，只需通过浏览器完成：选择素材、探测、设置去重参数、确认执行、查看自检、打开产物、决定交付或重新生成、批量裂变和查看审计记录。

页面定位：本地单用户 PC Web 工作台，不是视频剪辑器，不是上传平台，不是桌面客户端控制面板。

## 2. 业务与页面映射

| 业务依据 | 页面表达 | 验收结果 |
|---|---|---|
| PRD §5、§8、§9 | 素材选择与探测区 | 先 probe，展示分辨率、帧率、时长、编码、体积、MD5 |
| PRD §6、§14 US-01~US-04 | 去重参数区 | 强度档、六个维度、flip 方向联动 |
| PRD §9、US-07 | 人工确认弹窗 | 首次执行需确认，取消不得落产物 |
| PRD §8、§14 US-05 | 单条自检区 | MD5、分辨率、时长、成片下限、pHash 五项状态 |
| PRD §9、US-06 | 批量裂变区 | 数量、变体列表、距离矩阵、双重交付门 |
| SAD 安全边界、DD §3 | 权限与安全摘要 | assets 只读、output 写入、其他目录拒绝、删除硬阻断 |
| DD §5.1~§5.4 | 操作记录区 | 每步可追溯，错误与人工确认清晰区分 |

本蓝图不新增 PRD、SAD、DD 未定义的业务能力；“打开输出文件夹”是用户明确提出的验收便利操作，仅打开固定项目 output 目录，不接受任意客户端路径。

## 3. 视觉风格选择

### 3.1 选择

选择：`docs/04-UI原型/风格和样式积累/前端设计系统.md` 中的 **Argus / Fresh Professional Light**。

### 3.2 选择理由

当前产品是高信息密度的企业工具工作台，需要持续显示参数、状态、阈值、产物和审计记录。Argus 风格的浅色、轻量、克制、清晰层级更适合 1024×768 及以上的验收操作；苹果极简风的大留白、巨型标题和展示型 Hero 不适合作为本页面主工作区。

### 3.3 禁止混用

- 不使用苹果极简风的巨型 Hero、商城式导航、产品展示卡。
- 不使用深色霓虹、玻璃拟态、渐变背景或装饰性网格。
- 不使用系统 Emoji 作为图标。
- 图标统一使用项目已有 iconfont 或单一风格的内联 SVG。

## 4. 页面架构

### 4.1 PC Web 骨架

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 顶部工作区：品牌 / 页面名称 / 服务状态 / 打开输出文件夹                    │
├──────────────┬──────────────────────────────────────────────┬──────────────┤
│ 一级导航      │ 主内容：去重工作台                             │ 辅助面板       │
│              │ 1 选择素材 → 2 设置参数 → 3 生成 → 4 查看产物 │ 验收记录       │
│ · 去重工作台  │                                              │ 服务与权限摘要 │
│ · 批量裂变    │ 素材与探测                                   │ 最近操作       │
│ · 工具权限    │ 去重参数                                     │               │
│ · 审计记录    │ 单条自检 / 裂变矩阵 / 产物入口                 │               │
└──────────────┴──────────────────────────────────────────────┴──────────────┘
```

### 4.2 页面职责

仅保留一个主工作台页面，通过卡片、状态区、确认弹窗和右侧辅助面板承载 DD 已定义能力。不增加独立登录页、上传页、剪辑页或平台发布页。

### 4.3 主流程

```text
选择素材
  ↓
探测素材（必须先完成）
  ↓
设置强度 / 维度 / 翻转方向 / 裂变数量
  ↓
开始单条去重或批量裂变
  ↓
人工确认执行
  ↓
展示自检与产物
  ├─ 全部通过 → 可确认交付
  └─ 任一失败 → 显示原因 → 调参或重新生成
```

## 5. 页面区域规范

### 5.1 顶部工作区

内容从左到右：品牌标识“VU”、产品名“视频去重工位”、副标题“本地素材处理与验收”；右侧固定放置“打开输出文件夹”和服务状态。

服务状态至少包括：连接中、已连接、连接失败、重试中。状态不能只依赖颜色，必须同时有文字。

### 5.2 左侧一级导航

导航项：去重工作台、批量裂变、工具与权限、审计记录。当前版本可以是单页锚点或区域切换，但不得改变既有业务流程。

左侧下方显示安全摘要：

- `assets/`：素材只读
- `output/`：产物写入
- 其他目录：拒绝
- `delete_output`：硬阻断

### 5.3 主内容区

主内容顶部使用四步流程指示器：

1. 选择素材
2. 设置参数
3. 生成处理
4. 查看产物

步骤状态：未开始、当前、已完成、失败。当前步骤使用品牌蓝边框或底部指示线；已完成不能只用颜色表达，应有文字或图标辅助。

#### A. 素材与探测卡片

字段：素材下拉框、刷新素材、探测按钮；探测后展示文件名、分辨率、FPS、时长、视频编码、音频编码、码率、体积、MD5。

状态：加载素材、素材为空、加载失败、已选择未探测、探测成功、探测失败。

未完成探测时，去重和裂变按钮可以显示，但点击必须给出“请先探测”的明确提示，不得发起业务请求。

#### B. 去重参数卡片

第一行：强度档 `light / medium / heavy`，默认 `medium`。

第二行：六个维度开关：画面、微旋转、裁切、变速、去头尾、翻转；翻转默认关闭。

第三行：flip_mode 下拉框，只有启用翻转后才启用，选项为水平、垂直、90°旋转；启用翻转时必须明显提示该维度破坏性较高。

批量裂变数量：默认 5，范围 1~20；必须有数值约束和越界提示。

空选择状态：所有维度关闭时，页面提示“至少启用一个维度”，不发请求。

#### C. 单条自检与产物卡片

五项检查固定为：

1. MD5 已改变
2. 分辨率保持
3. 时长合规
4. 成片 ≥ 5s
5. pHash 自检

pHash 显示：avg、min、弱帧占比、method。当前实际判定口径为 `phash_avg >= 12 && weak_frame_ratio <= 0.10`；`phash_min` 仅展示，不作为当前判定门。signature 兜底时必须明确显示“签名兜底”，不得把非数值结果描述成数值门通过。

结果必须包含：输出文件名、源/新 MD5、源/新分辨率、源/新时长、应用参数、job_id。

产物操作固定包括：

- 打开输出文件夹
- 确认交付（仅五项全通过时可用）
- 再生成变体

“打开输出文件夹”只调用本机固定 output 目录接口，不展示任意路径输入框。

#### D. 批量裂变卡片

展示：源素材、变体数量、MD5 唯一性、矩阵是否通过、delivery_ready 状态、变体文件名与 MD5 摘要。

距离矩阵：对角线为自身；通过单元格为成功样式；过近单元格为失败样式；必须有图例和文字说明。

当 `matrix.all_pass=false` 时展示 separation 诊断，说明时间腿是否存在、flip 是否产生分散以及建议动作。只有 `all_unique=true && matrix.all_pass=true` 时显示可交付状态。

#### E. 右侧辅助面板

展示最近操作时间线：探测、人工确认、去重/裂变执行、自检结果、打开产物、失败和再生成。记录样式需要区分 audit、warned、blocked、error、human。

右侧面板不是业务主操作区，空间不足时允许下移或折叠，但不能隐藏主流程按钮。

```css

```

浅色表面：

```css
--surface-page: #F7F9FC;
--surface-card: #FFFFFF;
--surface-muted: #F1F5F9;
--text-primary: #1F2937;
--text-secondary: #64748B;

```

涨跌颜色约定不适用于本产品；成功使用绿色，警告使用琥珀色，危险/阻断使用红色。

### 6.2 排版

正文优先使用 `Noto Sans SC` / `Microsoft YaHei` / system sans-serif；等宽数据使用 `Consolas` 或系统 mono。

- 页面标题：24px / 500
- 区域标题：16px / 500
- 正文：14px / 400
- 辅助说明：12px / 400
- 数值和 job_id：12~13px mono

只使用 400 与 500 两档字重，避免过度强调。

### 6.3 间距、半径、阴影

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 24px;
--space-6: 32px;
--radius-sm: 8px;
--radius-md: 12px;
--radius-lg: 16px;
--shadow-card: 0 1px 3px rgba(15, 23, 42, .06);
--ease-standard: .2s cubic-bezier(.16, 1, .3, 1);
```

阴影仅用于区分卡片层级，禁止大面积发光、渐变和玻璃模糊。

## 7. 组件规范

### 7.1 Button

状态：default、hover、focus-visible、pressed、disabled、loading、success、error。高风险动作使用 warning 或 danger 语义，并保留确认弹窗。

按钮必须有可读文本；纯图标按钮必须有 `aria-label` 和 tooltip。

### 7.2 Card

白色表面、12px 或 16px 圆角、细边框、16px 内间距。一个卡片只承载一个清晰任务。

### 7.3 Status badge

状态徽标必须同时有文字：已连接、连接失败、通过、未通过、待确认、已阻断、可交付、不可交付。

### 7.4 Modal

人工确认弹窗包含：风险说明、即将执行的工具、关键参数、取消、确认执行。打开时焦点进入弹窗，Esc 可取消，关闭后恢复触发按钮焦点。

### 7.5 Check item

检查项不能只使用颜色。每项同时展示状态符号、状态文字和必要数值；失败项紧跟可执行的重试建议。

### 7.6 Matrix

矩阵表格固定列宽，窄视口允许横向滚动；对角线、通过、过近分别使用不同背景和文字，不依赖颜色单独表达。

## 8. 状态矩阵

| 区域 | 加载 | 空 | 错误 | 成功 | 禁用/无权限 |
|---|---|---|---|---|---|
| 服务 | 连接中 | — | 连接失败 + 重试 | 已连接 | 非本机来源拒绝 |
| 素材 | 加载列表 | assets 为空 | 列表加载失败 | 可探测 | 非白名单路径拒绝 |
| 探测 | 探测中 | 未选择 | 探测失败 | 展示媒体信息 | 未选素材禁用 |
| 参数 | — | 至少一维提示 | 参数越界 | 可执行 | flip_mode 随 flip 禁用 |
| 单条去重 | 执行中 | 未探测提示 | ffmpeg/Hook 失败 | 产物 + 五项检查 | 未全通过时交付禁用 |
| 裂变 | 批处理中 | 未探测提示 | 任务失败 | 变体 + 矩阵 | 双门不通过时不可交付 |
| 删除 | — | — | blocked 提示 | 不提供成功态 | 永久硬阻断 |
| 审计 | 读取中 | 暂无记录 | 读取失败 | 时间线 | 只读 |

## 9. 响应式规范

必须验收：1024×768、1280×800、1366×768、1440×900、1920×1080。

- 1440px 及以上：左侧导航 + 主内容 + 右侧辅助面板三栏。
- 1200~1439px：压缩两侧栏宽度，主内容保持可操作。
- 1024~1199px：右侧辅助面板移到主内容下方，主流程不隐藏。
- 小于 900px：仍为纯浏览器桌面布局，按区块纵向排列，不引入移动端底部 Tab。
- 所有卡片、矩阵和参数标签允许自然换行；按钮点击热区不小于 32px。

## 10. 可访问性

- 使用 `header`、`nav`、`main`、`aside`、`section`、`label` 等语义元素。
- 所有表单控件关联可见 label 或 `aria-label`。
- 所有按钮可通过键盘访问，`focus-visible` 有明显边框。
- 弹窗管理焦点并支持 Esc 关闭。
- 成功、失败、加载状态同时使用文字和非颜色提示。
- 尊重 `prefers-reduced-motion`。
- 文本与背景满足 WCAG 2.1 AA 对比度。
- 不使用系统 Emoji 充当业务图标；使用 iconfont 或统一 SVG 图标。

## 11. 后续工程实现规则
