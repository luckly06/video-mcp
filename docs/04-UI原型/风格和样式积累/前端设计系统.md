# RAG01 前端设计系统参考文档

> **版本**：v1.0 | **最后更新**：2026-05-23

---

## 一、设计理念

本设计系统基于 **Argus 风格**（Fresh Professional Light），以"轻量专业"为核心定位，服务于企业级知识库 / RAG 问答场景。

### 核心原则

1. **可读性优先** — 文字必须清晰、字号适宜、不刺眼
2. **克制** — 不要使用过于花哨的装饰性元素
3. **统一** — 保持整体协调
