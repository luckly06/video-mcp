## 一，关于DD的扩写
注意：初始的【SRS\02-方案设计\02-系统详细设计说明书【DD（Detailed Design）】.md】不动
SAD作为架构基线，在P0阶段冻结；
DD采用增量演进机制，保留历史版本，不允许无记录覆盖修改。扩写路径：SRS\05-扩展功能
——>
- 小迭代升v1.1原地扩写:{项目名}-DD-v1.1.md;

适用于：
- 已有模块设计细节调整
- 参数、流程、接口细节优化
- 不改变整体架构边界的设计变更


- 大范围扩展：
不直接修改主 DD，应通过 Addendum 增量补充。

命名规则：{项目名}-DD-v1.1.md

- 大扩展出增量补篇,名：
{项目名}_dd_v1.1/
    └── {项目名}_dd_p1_addendum.md
    
适用于：
- 新增功能模块
- 新增系统能力
- 新增架构范围
- 对原 DD 产生较大影响的扩展设计
