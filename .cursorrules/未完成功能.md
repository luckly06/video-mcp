# 未完成功能记录

> 适用范围：项目组所有组员
> 目的：集中记录「未做完」或「进行中」的功能，避免在 PRD / WBS / 开发环境配置.md 里散落备注

---

## 维护规则

### 什么时候写入

- 接手一个 issue，发现**前置依赖未完成**无法开工时
- 一个功能做了部分就停下来（被打断 / 当天收工 / 临时切任务）
- 验证时发现**某条验收标准不满足**，需要后续再补

### 写入格式

每个未完成项写明：`### [YYYY-MM-DD] 标题`，含关联 issue、阻塞原因、当前进度、下一步行动、关联文件。

### 删除 / 归档时机

当一项变成「已完成」后，从本文件删除该条目。
